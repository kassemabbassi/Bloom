# Bloom: AI-Powered Mental Wellness Application

## Overview

Bloom is a web-based mental wellness application designed to support emotional well-being using generative AI. Our solution integrates multiple AI-driven features to reduce mental health stigma and encourage positive practices through personalized interactions.

## Key Features

### AI Wellness Chatbot

- Provides mental health support through conversational AI
- Uses Gemini 2.0 Flash API adjusted for wellness-related responses
- Features keyword-based filtering for mental health topics
- Offers empathetic responses and crisis resources when needed

### Emotion Detection

- Analyzes facial expressions to detect mood
- Generates personalized voice-based advice
- Uses FaceAPI.js for in-browser emotion detection
- Leverages ElevenLabs API for text-to-speech conversion
- _Note: Subject to API usage limitations_

### Mood Tracker

- Allows users to log their emotions and intensity levels
- Supports optional journaling notes
- Provides AI-generated insights based on entries
- Uses Gemini 2.0 Flash fine-tuned for mental health advice

### Guided Meditation

- Delivers personalized meditation sessions based on emotional needs
- Recommends tracks for specific purposes (anxiety relief, sleep aid, etc.)
- Currently uses pre-recorded meditation clips
- Future plans: AI-generated sessions via ElevenLabs

- Encourages proactive emotional self-care
- Provides crisis resources for at-risk users
